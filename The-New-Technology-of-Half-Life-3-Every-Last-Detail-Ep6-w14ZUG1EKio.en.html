Overview

Tyler inventories Source 2 engine-level features he expects to appear in HLX, covering hair strand simulation, VData-driven content, procedural audio, Speech Graphics lip-syncing, temporal anti-aliasing and upscalers, weather and wind, ray tracing, AI level of detail, distance fields, mesh shaders, Pulse scripting, and Animgraph 2. The episode is primarily a technical roundup rather than a new leak: several systems have been discussed before, while the freshest specifics are Animgraph 2’s shipping dates in Deadlock and Counter-Strike 2 and the December 2025 Dota 2 authoring tools. Tyler is confident about features visible in engine and shipped-game files, but hedges on HLX-specific use, the scope of ray tracing, and his font theory. No release date, build number, or new HLX asset is presented.

VData drives HLX weapons, NPCs, crates, and grenades

  • Description: Tyler describes VData as a data-driven system that lets developers iterate on game mechanics without recompiling game code. He says it is core to modern Source 2 games and underlies most of Deadlock, where every hero and ability is stored in VData files for quick iteration, patching, and modding. He states that this carries over to HLX and that “we know for a fact” weapons, NPCs, crates, crate items, and grenades are editable by the end user without recompilation. He cites a community recreation of Neon Prime, built from leftovers in early Deadlock versions, as a demonstration of the capability.
  • Confidence: Mixed — the HLX asset categories are explicitly asserted as fact and Deadlock’s VData use is visible in a shipped game, but the claim that the Neon Prime recreation would have been impossible without VData is Tyler’s inference.
  • Category: Engine feature
  • Source: Deadlock shipped game files and prior VData datamines, plus the community Neon Prime recreation mod cited by Tyler.
  • Earlier mentions: References prior VData discussion (“as we’ve discussed many times”) but does not name a specific earlier video.
  • Verification: needs follow-up — inspect Deadlock/HLX VData files for weapon, NPC, crate, crate item, and grenade definitions, and check the Neon Prime recreation mod’s implementation.

Animgraph 2 architecture and file format

  • Description: Tyler says Animgraph 2 is the new animation resolve system intended to replace Animgraph 1, which was not networked efficiently in multiplayer titles and caused large bandwidth consumption. Instead of one Animgraph file containing animation and skeleton data in the VModel, Animgraph 2 stores animations in separate VNM clip files and skeletons in VNM skull files, so they no longer need to be present in the VModel. Skeletons support bone-level LOD, with significantly fewer bones at low LOD levels. Graphs can have multiple variations: core graphs contain purely resolve logic, while specified variations can reference overridden animation clips and overrideable graphs. The state-machine resolve is completely different and lacks some Animgraph 1 features for optimization.
  • Confidence: Fact — specific file extensions, data layout, and graph behavior are described as facts from the engine and tooling.
  • Category: Engine feature
  • Source: Source 2 animation tooling and Animgraph 2 file definitions.
  • Earlier mentions: None identified in this video.
  • Verification: needs follow-up — inspect VNM clip/VNM skull formats and Animgraph 2 graph definitions in Source 2 tools.

Dota 2 December 2025 Animgraph 2 authoring tools

  • Description: Tyler says a Dota 2 update in December 2025 adds a “create default AnimGraph 2” option. It can create an AnimGraph 2 graph, convert a render mesh file into an AnimGraph 2 skeleton, and convert all animation sequences referenced in a model into Animgraph 2 clips. The clip creator also respects the subtractions used to create additive animations and anim events, converting them to a new legacy format. The same update adds AnimGraph 2 list and skeleton list support directly into Model Doc so newly authored Source 2 models can reference Animgraph 2 resources. Hammer also adds an AnimGraph 2 identifier field to replace the studio model system for dynamic models, letting a prop_dynamic entity run an Animgraph 2 identifier.
  • Confidence: Fact — a named update and specific tool options, fields, and conversions are described.
  • Category: Engine feature
  • Source: Dota 2 December 2025 update tooling and Source 2 Model Doc/Hammer changes.
  • Earlier mentions: None identified in this video.
